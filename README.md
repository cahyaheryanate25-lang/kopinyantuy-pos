## 📌 Fitur Utama

### 📱 1. Fitur Pelanggan (Self-Service Order)
- **Scan QR Meja:** Pelanggan mengakses menu sesuai nomor meja.
- **Katalog Menu:** Filter menu berdasarkan kategori (Kopi, Non-Kopi, Snack).
- **Keranjang Belanja:** Melihat rincian item dan total harga secara *real-time*.
- **Cetak Struk Digital:** Bukti pemesanan otomatis beserta Nomor Order.
- **Sistem Rating:** Memberikan ulasan dan rating pada menu.

### 💻 2. Fitur Kasir / Admin (Dashboard)
- **Monitor Transaksi:** Daftar pesanan masuk secara *real-time*.
- **Ringkasan Penjualan:** Monitor total pesanan dan pendapatan harian.
- **Detail Transaksi:** Melihat rincian pesanan pelanggan.
